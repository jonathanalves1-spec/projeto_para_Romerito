Sobre a Atividade Acadêmica

Este site foi desenvolvido como projeto prático para a disciplina de Autoria Web, atendendo a todos os critérios e diretrizes estabelecidos para o projeto em grupo multipágina.

Ficha Técnica da Atividade

  • Disciplina: Autoria Web
  • Organização: Grupo de 4 integrantes
  • Período de Execução: 10/10/2026 a 31/10/2026
  • Pontuação da Atividade: 50 pontos
  • Entrega: Repositório GitHub com README.md

Objetivos Técnicos Alcançados

  • Construção de site estático com exatamente 4 páginas HTML interligadas.
  • Uso de folha de estilo externa única (style.css).
  • Aplicação de conceitos de layout com CSS Flexbox responsivo.
  • Estruturação semântica com tags header, nav, main, section e footer.

Alinhamento com as Regras da Atividade

Estrutura HTML

Cada página possui conteúdo próprio e exclusivo, contendo pelo menos duas seções estruturadas e elementos semânticos.

Flexbox & CSS

Menu de navegação e galerias organizados com display: flex, gap, justify-content, align-items e flex-wrap.

Unidade Visual

Todas as 4 páginas compartilham a mesma paleta de cores, tipografia e cabeçalho/rodapé padronizados.
